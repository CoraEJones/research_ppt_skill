# 质量清单

每次交付独立预览或整合稿前走完本清单。未通过的项要在交付说明里写明，不要假装已经检查。

## A. 文件与版本

- [ ] 用户原稿未被覆盖；新文件用新文件名。
- [ ] 用户明确删除的页没有被加回；用户手改页的措辞和布局被保留（除非用户要求改这些页）。
- [ ] 整合按内容对应，而不是按过时页码硬接。
- [ ] 页码与实际页序一致；页内“见第 X 页”、议程范围、讲稿中的页码指称已一起改。
- [ ] 交付说明里写的是真实、完整的文件路径和页数。

## B. 数据与结论

- [ ] 每一页上台的数字都能指到清单中的来源（配置、检查点、数据集、范围、单位、种子）。
- [ ] 同一对比里的表、图、动画、讲稿使用同一检查点与同一统计口径，没有把“最后一轮 / 最优检查点 / 另一轮次”混在一起。
- [ ] 符号和坐标的含义已按源码或数据说明核对，没有按变量名推测。
- [ ] 没有把旧模型、旧坐标系或旧缓存的图，用来支撑当前模型的结论。
- [ ] 伪彩或逐帧归一化的显示，只写成定性观察，没有编造物理强度、相关性、可辨识性或精度。
- [ ] 没有把两类光源、两类发射或两个对比对象，误写成两次曝光或双帧编码。
- [ ] 全局指标与局部 / ROI / 边缘证据一致被交代；没有用全局误差变好来暗示细小目标已经恢复。
- [ ] 单次种子或单次对照，没有被写成“机制已证实”。
- [ ] 页面上没有免责式套话；同时也没有把未稳住的主张改成更肯定的结论。不确定的话已改成事实，或已从页面删除、仅在讲稿保留为假设。

## C. 视觉与排版

- [ ] 16:9；默认风格下标题带、左条、标题字号和主色正确，或已按用户模板执行。
- [ ] 可见文字均为整数 pt，且 ≥ 18 pt（含图内标签的放置后大小、表、引用、结论条）。
- [ ] 中文默认微软雅黑，西文默认 Calibri，或已改用用户指定字体。若发生回退，交付说明写明实际字体，没有把回退称作默认字体已装上。
- [ ] 无分层项目符号；一页一个主要结论；结论条与下一页衔接或能收束本模块。
- [ ] 文字没有被裁切、没有贴死边框、没有与柱顶数值 / 色条 / 图例重叠。
- [ ] 结构图框内文字有足够边距，没有靠缩小字号硬塞。
- [ ] 图、表、色条的范围、单位和图例术语与正文一致（同一概念不要两个名字）。
- [ ] 默认没有机构或实验室标识；未经授权的 logo 或错误身份信息未出现。

## D. 公式、引用、动画与讲稿

- [ ] 公式为可编辑原生对象；行内数字和单位没有用衬线普通文本或截图冒充。若当时无法写入 OMML，已事先说明并获得用户对替代方案的批准，没有把未批准的图片公式称为已满足要求。
- [ ] 若预览工具无法正确显示原生公式，已在真正的演示软件中抽查，并在说明里写明限制。
- [ ] 引用格式全篇统一，期刊 / 会议名加粗+斜体，字号 ≥ 18 pt；没有编造卷期或页码。
- [ ] 需要逐步出现的推导或流程，已按点击顺序检查；**没有把静态 PDF / 截图当作动画已生效的证据**。
- [ ] GIF 能播放、来源和帧含义清楚；显示口径（裁切、放大、归一化、字幕遮挡）已在讲稿中如实说明。
- [ ] 讲稿语言符合本轮约定，内容与页面一致，术语前后统一，没有引用过时页码。

## E. 字体回退与预览诚实性

- [ ] 已检查实际可用字体与文件中声明的字体是否一致。
- [ ] 若软件做了字体替换、公式漏渲染或颜色偏差，交付说明里如实写出，不把预览图当成最终观感。
- [ ] 预览用的联系表和单页图已打开过，至少覆盖所有新改页，以及含公式、动画、对比表、色条的页。

## F. 传输与校验

- [ ] 大文件仅在用户允许时拷到其电脑；没有把渠道限制写成固定的体积上限。
- [ ] 拷贝完成后用校验和对照源文件；失败则分段重传并再校验，不修改内容来“减小体积”，除非用户另行要求做压缩版（压缩版须另存，并说明与原文件的差异）。
- [ ] 若拷贝尚未完成或机器离线，明确说文件目前只在哪一侧，而不是提前宣布已经送达。
