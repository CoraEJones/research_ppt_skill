# 提示词模板

按需取用，把方括号里的内容换成当前项目的真实信息。不要把未发表的具体结果写进可公开的仓库示例中。

## 1. 开工说明（给制作方）

```text
请按 research-ppt-skill 做一组科研组会 PPT。

平台与交付：
- 成品为可在 PowerPoint 中打开的 .pptx
- 先给 [独立预览 / 明确要求一次性整合]
- 不要覆盖我的原稿；我删掉的页不要加回来

语言与风格：
- 幻灯片语言：[中文 / 英文]。按我填写的来，不要自行改成另一种
- 备注讲稿：[与幻灯片相同 / 中文口播，约 300 字 / 其他]
- 风格：16:9，主色 #316886，浅灰标题带 + 左侧蓝条，图、公式和底部灰色结论框为主，不用分层项目符号
- 中文用微软雅黑，西文用 Calibri。环境里没有时写明实际回退字体，不要把回退说成已经装了默认字体
- 可见文字整数且 ≥ 18 pt，包括图内标签（按放置后大小）和引用
- 公式用原生可编辑公式（OMML），含行内数字和单位。写不出 OMML 时先告诉我，不要改成图片公式
- 机构或实验室标识：不要放。只有我另外授权并确认身份时，才使用我提供的文件

数据规则：
- 只使用我给出的结果和文件，不要自行推算或补实验
- 先列出数据清单：模型版本、坐标与单位、数据集、预处理/归一化、检查点、种子、指标统计范围
- 表和图必须对应同一检查点与同一口径
- 不能确定的结论不要写在页面上，可以放进讲稿当工作假设

本轮范围：
- 底稿：[文件名或“从空白开始”]
- 要讲的模块：[模块及其要回答的问题]
- 权威数据与图：[附件或目录，不包含私人绝对路径也应说明文件名]
```

## 2. 请用户确认的故事板

```text
下面是按页列出的故事板。每一页包含：要回答的问题、证据、一句结论、与下一页的衔接。
请直接改页序、删页或改结论。确认前我只交付故事板，不整合进全稿。
```

## 3. 小组预览

```text
请先做第 [A–B] 页的独立 PPT（或本模块 3–6 页），附上这些页的预览图和讲稿。
确认后我再让你整合进全稿并统一页码。
```

## 4. 明确要求一次性整合

```text
请在我这份删减版的基础上直接改并给出整合稿：保留我的删页决定、页序与手改内容，不恢复删页；只更新 [列出模块]，统一页码和讲稿，另存为新文件，不要覆盖这份底稿。
```

## 5. 数据清单（制作前必填）

```text
请先不要做页，先核对并列出：
- 每个数字来自哪一次运行 / 哪一个检查点（最后一轮、验证最优，还是指定轮次）
- 坐标系和每个符号的定义、单位
- 数据集、划分、预处理和归一化
- 指标的距离或 ROI 范围
- 图、动画与表格是否来自同一份结果
如果两处对不上，指出冲突，不要自行取平均或改数字。
```

## 6. 改某一页结论（避免过度推断）

```text
请只根据已核对的事实改这一页的结论条和讲稿。
可以写本次对照中看到的现象，不要写“已经证明了某种机制”。
显示用动画如果做了逐帧归一化或伪彩，只保留定性描述。
```

## 7. 公式、引用与动画

```text
请检查全稿：
- 所有公式是否为原生可编辑对象，包括带单位的数字
- 引用是否统一为 Author et al., Venue, vol, pages (year)，期刊/会议名加粗+斜体，且 ≥ 18 pt
- 没有页码的文献不要补页码
- 第 [X] 页的推导/流程是否按点击逐步出现；不要用 PDF 预览代替 PowerPoint 里的实际播放检查
```

## 8. 保护删页与手改

```text
请以我刚上传的版本为唯一底稿。我删除的页不要恢复。
未点名要改的保留页，不要改措辞、图和动画。
整合后按实际页序重排页码，并同步修改交叉引用和讲稿。
```

## 9. 验收

```text
请按质量清单做一遍：裁切与重叠、字号、字体回退、数据口径、页码重映射、公式、引用、动画/GIF、讲稿、原稿是否被覆盖。
通过项与未通过项分开列出。静态预览不能作为动画通过的证据。
```
