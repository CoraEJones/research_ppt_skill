# 匿名案例：一次组会稿的迭代（过程示例）

本案例只保留可复用的过程，不包含真实姓名、机构、路径、机器信息，也不包含未发表工作的具体数字、图或原 PPT。细节已改写或省略。

## 目标

做一次计算成像方向的组会报告：在已有工作底稿上，补两块内容——系统正向模型的说明，以及一种网络结构改动的对比——最后按讲者自己删减过的页序整合成一稿。

## 输入

- 讲者的已有 PPT，以及后来一份**亲自删过页**的版本
- 指定检查点上的指标表、重建预览和若干原理动画
- 风格要求：英文幻灯片、中文口播讲稿、图和结论为主、公式可编辑、引用格式统一
- 明确限制：不要覆盖原稿；删掉的页不要加回来；新页先独立预览，确认或明确要求整合后再合并

## 需求是如何迭代的

1. **先收集，再做页。** 底稿、权威表、动画和风格一起对齐。缺检查点或坐标定义时，先问清楚，而不是用“看起来像”的旧图顶上。
2. **故事板按模块而不是按旧页号。** 每一页写要回答的问题、证据、结论和衔接。讲者后来删了不想讲的页，后续整合以删减版为底。
3. **小组预览。** 新模块先以独立 PPT 和单页预览交付，避免一上来改全稿。
4. **中途纠正了错误结论。** 例如：一度根据旧缓存写出“图案会平移、中心和离轴表现不同”；讲者指出当前模型在固定视角坐标下并不带这种平移。于是撤回旧结论，动画改成固定窗口里的纹理变化，并且只做定性描述。
5. **补做结构对比时保持克制。** 全局指标在一种条件下变好、在另一种条件下变差，不能直接写成“某种分支策略已被证明更好”。细小目标是否被恢复，另用局部观察说明，不与全局误差混为一谈。
6. **明确要求整合后再并稿。** 统一页码、交叉引用和讲稿；原稿另存保留。

## 制作方负责的部分

- 把模块串成可讲的故事，控制单页重点和字号
- 重画可编辑的结构示意图和对比表，统一引用格式
- 把检查点、范围和术语在表、图、讲稿之间对齐
- 渲染预览，检查裁切、重叠、页码和讲稿同步
- 按讲者允许的方式交付文件，并报告真实路径

## 讲者把关的部分

- 删哪些页、保留哪些原话
- 哪一份结果是当前版本，哪一份动画对应当前模型
- 坐标和符号的含义
- 哪些结论可以上台，哪些只能作为讲稿里的工作假设
- 是否现在就整合，以及大文件是否拷到本机

## 出现过的问题与修正（可复用）

| 问题 | 修正 |
|---|---|
| 用验证集最优检查点的图，去解释另一轮次的表 | 全部分对照改到同一检查点；对不上的旧图不用来解释新表 |
| 辅助坐标的名字像深度或径向量 | 回源码核对：它是光线方向余弦，页面和讲稿改用正确含义 |
| 旧模型缓存里有视角映射和平移，被拿来解释当前无平移模型 | 旧图整组停用；改用当前模型、固定窗口的定性动画 |
| 显示 GIF 做了裁切、放大和逐帧拉伸 | 只讨论可见纹理变化，不报物理强度或相关值 |
| 把两类照明的并排动画当成两次曝光 | 改正为两类发射条件的对比，不做双帧比值 |
| 全局误差略有升降，被说成小目标已经（或完全没有）恢复 | 同时报告局部目标的恢复情况，不互相替代 |
| 单次训练种子的对比，被写成机制结论 | 页面只保留对照现象；机制解释放进讲稿，并说明仍待重复验证 |
| 预览里公式看起来被裁切、或动画在 PDF 里看不到 | 如实说明静态预览的限制，请在 PowerPoint 中抽查，不宣称已经验证播放 |
| 想沿用旧页码去改交叉引用 | 按内容重新映射，页码与讲稿一起改 |

## 可对外展示的“前后”差异（不涉及具体结果）

- 前：结论写成“深度只让图案平移”。后：在固定视角窗口里看局部纹理是否随深度变化，并标明这是显示层面的定性观察。
- 前：一张总表既比全局误差又暗示局部都改善。后：全局口径与局部目标分开讲，避免用一个数字概括两种现象。
- 前：不同检查点的图和表混排。后：对照组共享同一检查点和同一统计范围。
- 前：引用字号和格式不统一，公式有的是图片。后：引用统一格式且不小于 18 pt；公式改为可编辑对象（在工具支持的前提下）。

## 成品如何交付

独立预览页与整合稿分开存放，不覆盖讲者上传的底稿。交付时报告页数、改了哪些页、哪些结论被撤回，以及预览手段不能覆盖的检查项（例如点击动画须在演示软件中确认）。
