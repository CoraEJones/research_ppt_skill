# 适配真实页示例

以下示例取自经授权的最终演示文稿第 22、23、43 页。它们是**去标识、精简结论措辞后的真实页适配版**，不是原页原样发布，也不是新生成的研究结果。保留完整 16:9 页面、原理图像、蓝色标题和底部灰色结论框；页脚标识整形删除，留白保留。只提供 PNG/GIF，不包含可编辑演示文稿。

## 可直接用于主页的图注

- **`principle-fixed-uv.gif` / `slide-fixed-uv.png` — 用动态原理替代段落堆叠。** 左侧播放固定 uv 可见窗口的真实序列，右侧保留标注深度为 1.00 m 与 0.20 m 的静态证据，底部灰框集中表达定性结论。来源：第 22 页适配；PNG 为静态导出，GIF 为原有序列的整页合成。
- **`principle-comparison.gif` / `slide-comparison.png` — 让对照在同一视野中发生。** 两类 TX 的 seed 7 可见纹理并列，保留粗斑块与细颗粒的视觉证据，用一句灰框结论收束。来源：第 23 页适配；这是两类 TX 对比，不是双曝光。
- **`slide-coordinate-architecture.png` — 用结构图讲清变量与不变量。** 输入分组、共享主干和分支输出形成完整阅读路径；灰框强调只改变首层卷积。来源：第 43 页适配；不含详细数值性能表。

## 这些示例说明为什么使用这个 skill

原理用 GIF 展示过程，证据用图像保留，结构关系用示意图表达，最后用灰色结论框指出观众应该记住什么，而不是把讲稿堆在页面上。

## 来源、编辑与证据边界

- 三张 PNG 均由最终演示文稿的对应实际页面导出，保留原有英文内容与结构。完整删除页脚标识图片和页码底色；仅保留可选原页码。三页灰框文字均精简为独立可读的一句话。
- 两张 GIF 是上述适配页面的整页动画，不是未改动的原始 GIF 文件。动画仅替换原有图像区域；保留原序列全部 64 帧、原顺序、100 ms/帧，共 6.4 秒，循环播放。静态页面装饰经过 GIF 调色板压缩；动态纹理采用最近邻显示，并逐帧验证编码后所显示的源 RGB 像素不变。
- 每个动态面板来源为固定窗口的 **96×93 可见源像素**。原标注窗口底部 3 行被遮挡，未补绘、未推测缺失像素；没有新增光学计算、平移、配准或逐帧强度归一化。
- 无平移版本身份依据素材提供者的确认，未独立绑定生成源码。伪彩与归一化参数未知，因此只能说明显示纹理的定性变化，不能据此推断物理光强、相关性、深度灵敏度或性能优劣。原理页与结构页不被宣称为同一模型的数值验证。
- 已逐页检查静态页面，检查两段动画全部 128 帧的动态区域及固定页面文字；未发现机构、实验室、作者姓名、网址或标识。PNG 不带 EXIF/文本元数据；GIF 不含注释、文本扩展或个人标识元数据，仅保留播放所需控制信息。压缩包不含 PPTX、隐藏幻灯片或演示文稿媒体目录。
